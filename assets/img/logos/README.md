# Official logos

Add these two files (PNG, transparent background, about 400px tall) and they replace
the text badges across the site automatically:

- `bhs-approved.png` – the official "BHS Approved" logo. The British Horse Society supplies
  approved centres with their approved-centre artwork; use that version.
- `east-down-pony-club.png` – East Down Pony Club / The Pony Club logo, from the branch.
